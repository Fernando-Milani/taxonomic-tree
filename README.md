# Taxonomia de Espécies com Dendrograma

## Sobre o projeto

Projeto desenvolvido com foco na organização e classificação de espécies de seres vivos utilizando estruturas taxonômicas e representação hierárquica através de dendrogramas.

O principal objetivo do projeto é transformar dados biológicos em uma estrutura organizada e relacional, permitindo representar relações hierárquicas entre espécies de forma escalável e padronizada.

A proposta foi desenvolvida com forte foco em conceitos de engenharia e modelagem de dados, utilizando estruturas hierárquicas para organizar informações taxonômicas e possibilitar consultas, agrupamentos e visualizações mais eficientes.

O dendrograma atua como representação visual da hierarquia dos dados, permitindo identificar agrupamentos e relações entre diferentes níveis taxonômicos.

Além da parte visual, o projeto envolve desafios comuns de engenharia de dados, como:

* Organização de grandes volumes de informações categóricas
* Padronização de nomenclaturas
* Estruturação de relações hierárquicas
* Modelagem relacional de entidades biológicas
* Consistência e integridade de dados
* Facilidade de expansão para novas espécies e categorias

O projeto também foi pensado para permitir futuras integrações com análises de dados e visualizações mais avançadas, mantendo uma estrutura organizada e reutilizável.

## Estrutura taxonômica

O projeto considera relações hierárquicas entre categorias biológicas, incluindo:

* Reino
* Filo
* Classe
* Ordem
* Família
* Gênero
* Espécie
